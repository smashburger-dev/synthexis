# Perception students

The three CoreML models the plugin runs on the Neural Engine. `plugin/install.sh` compiles them into `~/Library/Application Support/synthexis/models`. Training code: `tools/train/`; results, gates and every selection decision: [`probes/train-students/RESULT.md`](../../probes/train-students/RESULT.md). `students.json` records run, epoch and measured numbers for each model.

| file | run | backbone (pretrained) | input | outputs |
|---|---|---|---|---|
| `seg.mlpackage` | seg-a-s0 | MobileNetV4-Conv-Small + LR-ASPP, 1.51M params | `image` 384x216 RGB, `prev_mask` 1x1x216x384 fp16 (previous class map / 6, zeros when unknown) | 1x7x216x384 logits: background, person, face, eye, mouth, hand, object |
| `hand.mlpackage` | hand-chir | MobileNetV3-Small, 1.57M params | `image` 128x128 RGB hand crop | keypoints 1x21x2 (crop pixels), finger logits 1x5 (thumb to pinky, extended = logit > 0), handedness logit 1x1 (> 0 = the person's right hand) |
| `face.mlpackage` | face-a-s1 | MobileNetV4-Conv-Small + LR-ASPP, 1.51M params | `image` 128x128 RGB face crop | 1x3x128x128 logits: other, eye, mouth |

Output names are generated by the converter; pick outputs by element count (42, 5, 1 for the hand model).

The default `hybrid` backend uses seg and hand, and takes the face from Apple Vision landmarks. The face model is the fallback where Apple Vision is not available. Its mouth mask is usable (held-out IoU 0.705), its eye mask is not (0.243).

## What the weights contain

Only the trained parameters. The training data, recordings of one person's face and hands with their labels, is not in this repository and is not needed to run the models.
