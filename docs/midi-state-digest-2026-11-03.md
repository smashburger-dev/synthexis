## Pong preset

Barely defined and not built. The whole definition is spec/synthexis.yaml:213-219 plus feature F41 (spec/synthexis.yaml:59): the frame border is one ring; a throw ray hits a side (top, right, bottom, left) and a perimeter position 0..1; a visual projectile flies and bounces like Pong and every wall hit is an event with speed (213-214). The ring is split into user-sized segments, each assigned to a parameter, a MIDI note or a pattern slot (215). A hit on a parameter segment fires a one-shot ramp (shapes up, down, triangle, exp decay, ADSR, bounce, steps; depth from throw speed; length tempo-synced or in ms; overlapping ramps sum and clamp) (216). A hit on a note segment plays a note, position quantized to the scale, velocity from speed (217). Options: grid quantization of hits, max bounces, projectile speed and gravity (218). Border zones and hit ramps live only inside this preset (Noa 10-27, 219). The throw it depends on is motion.primitives.throw: speed peak above v_min then release or stop, with direction, speed, release point and the border perimeter position (spec/synthexis.yaml:202), status planned (211). Orb feeds Pong: a fast separation throws the orb as a projectile into Pong, an explode fires a fan of projectiles (spec/synthexis.yaml:220-224). Other mentions only name it: roadmap 'presets Pong and Orb ... needed for the demo, Noa 11-03' (docs/roadmap.md:44); ux 'Pong and Orb as extras' and scoped 'Later' (docs/ux-plugin.md:182, 370); ontology preset 'throws bounce off the frame border, wall segments fire ramps or notes' (tools/mapping/ontology.yaml:302) and intent preset (271); the parser outputs 'I:preset preset:pong' (plugin/parser/tests/fixtures/dev200-v11-q8-s0123.jsonl, 8 rows) from synthetic training weight pong 13 (tools/mapping/edits.yaml:233), but the plugin only prints that line (plugin/synthexis/src/sentence.rs:1081). Data exists: block H recorded throws at the four borders and orb hold/throw (docs/recording-protocol.md:30), with Spark Open timelines for evaluation (probes/motion-labels/RESULT.md:11). Missing from every doc: default number and size of segments, what each wall plays by default, the projectile's visual and physics constants, whether a hit on a pattern segment starts or toggles the pattern, how many projectiles can live at once, how a hit is quantized when the transport is stopped, and how the zones are edited in the UI. No code exists in plugin/synthexis/src for throw, projectile, border or ramp (grep for throw/swipe/orb finds nothing); orb.* sources are in the ontology (tools/mapping/ontology.yaml:182-185) but not engine signals (plugin/synthexis/src/signal.rs:44-83).
